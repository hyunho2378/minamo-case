# MINAMO 케이스 스터디

XR 드로잉 글라스 MINAMO의 전시용 케이스 스터디 사이트. 제19회 디지털인문예술전공 프로젝트 전시회(2026. 12. 1.~12. 3.) 포스터 QR로 연다.
작품은 2026 한림대학교 캡스톤디자인 과제이고, 후쿠오카 오호리 공원과 舞鶴公園의 밤 수면에 처음 만난 사람과 함께 그리는 서비스다.

## 실행

```
npm run dev      # http://localhost:5201/minamo-case/
npm run build    # vite build --minify false (lightningcss 네이티브 바인딩이 없어 압축을 끔)
npx vite preview --base /minamo-case/ --port 5201
```

## 배포 준비

GitHub Pages 주소 `https://hyunho2378.github.io/minamo-case/` 를 기준으로 `vite.config.js` 의 `base` 를 `/minamo-case/` 로 맞췄다.
그림 경로는 `import.meta.env.BASE_URL` 를 붙여 만들므로 하위 주소에서도 깨지지 않는다(미리 보기에서 그림 43장 중 깨짐 0).
빌드 때 `dist/index.html` 을 `dist/404.html` 로 복사하는 플러그인을 넣어, `/minamo-case/ja` 처럼 없는 경로를 새로고침해도 같은 화면이 열린다.
푸시와 배포는 하지 않았다.

포트는 지시의 5199 대신 5201을 쓴다. 이 컴퓨터의 5199는 미리 프로토타입이 쓰고 있었다.
폭을 정확히 재려고 `public/__frame.html?w=1440&h=900` 처럼 고정 폭 iframe 도구를 함께 둔다.
틀은 경고등 음성 안내 케이스 스터디(`../telltale-voice`)의 package.json과 node_modules를 복사해 시작했다. Vite, React 18.

## 두 판

머리 오른쪽에서 KO와 KO+JA를 고른다.

- KO: 한국어만
- KO+JA: 장표와 같은 방식으로 한국어 줄 아래에 작은 회색 일본어 줄이 붙는다

판을 바꾸면 일본어 줄만큼 글이 길어지므로(1440에서 26,874px에서 28,527px), 바꾸는 순간 보고 있던 섹션에 화면을 다시 맞춰 자리가 튀지 않게 했다. 섹션 수와 순서, 각 섹션 안의 배치는 두 판이 같다.

## 배정 사례

플러스엑스 NICE홀딩스(id `niceholdings`), 원본 `https://www.plus-ex.com/source/iframe/portfolio/niceholdings.html`
측정 문서: `docs/측정.md`

고른 이유는 세 가지다. 첫째, 바탕이 어두운 `#141920`이면서 흰 면과 회색 면을 번갈아 써서 장표의 검정과 회색, 흰 면 리듬을 그대로 옮길 수 있다. 둘째, 제품과 화면을 전체 폭으로 크게 보여 주는 구성이라 MINAMO의 제품 렌더와 장면 사진이 들어갈 자리가 넉넉하다. 셋째, GSAP ScrollTrigger와 WOW 등장 연출, Swiper 흐름 줄, 3000px 고정 구간까지 옮길 연출이 남아 있다. 이미 쓴 사례(tuniverse, musinsa, sphere, emart, lazynight, eql, lpoint1, leferi, unix_web, kolonmall)와 겹치지 않는다.

플러스엑스의 그림, 영상, 로고, 글꼴, 문구는 쓰지 않았고 코드는 새로 썼다.

## 인터랙션

### 스스로 재생되는 데모

| 자리 | 가만히 두면 | 손을 대면 |
|---|---|---|
| 표지 | 먹 입자가 한 줄씩 흘러 번진다 | 마우스와 손가락을 따라 그려진다 |
| 디자인 키워드 Drop | 보이지 않는 펜이 1~2초마다 수면에 먹 원을 떨어뜨린다 | 누른 자리에 원이 떨어진다 |
| 디자인 키워드 Flow | 가상 펜이 수면을 천천히 휘저어 줄무늬가 흐른다 | 끌면 그 자리에서 흐른다 |
| 디자인 키워드 Blend | 가상 펜이 연두와 회색 무늬를 섞는다 | 끌면 두 무늬가 섞인다 |
| 장면 | 9.2초 주기로 연두 선이 4.6초 동안 그려지고 2.2초 동안 지워지며 사진이 1.06에서 1로 줄어든다 | 조작 없음 |
| 휴대폰 관람 | 수면 정보, 수면 보기, 작가 카드가 3.6초마다 바뀌고 단계 이름이 따라 바뀐다 | 단계 이름을 누르면 그 화면으로 간다 |

조작이 멈추고 2.4초가 지나면 키워드 세 칸은 다시 자동 시연으로 돌아간다. 화면 밖으로 나가면 모든 데모가 멈춘다(IntersectionObserver). `prefers-reduced-motion: reduce` 에서는 전부 정지 그림이다.

### 직접 하는 조작

| 자리 | 조작 | 하는 일 |
|---|---|---|
| 표지 | 마우스나 손가락을 움직임 | 墨流し 입자가 흐름장을 타고 연두 선으로 흘러 번진다. 손을 대지 않아도 한 줄씩 천천히 흐른다 |
| 솔루션 | 가운데를 좌우로 끌기 | AS-IS와 TO-BE 사진 경계가 따라 움직인다 |
| Drop | 누르기 | 누른 자리에 먹 원이 떨어져 동심원으로 퍼진다 |
| Flow | 끌기 | 깔린 줄무늬가 손을 따라 물결을 타고 흐른다 |
| Blend | 끌기 | 연두 무늬와 회색 무늬가 손 둘레를 돌며 섞인다 |
| 장면 | 스크롤 | 밤 수면 위에 연두 선 두 줄이 그려지고 사진이 1.1에서 1로 줄어든다 |
| 휴대폰 관람 | 스크롤 | 수면 정보, 수면 보기, 작가 카드 세 장이 고정 화면에서 차례로 바뀐다 |
| 머리 | KO와 KO+JA 누르기 | 일본어 줄이 붙고 빠진다. 보던 섹션 자리를 유지한다 |

`prefers-reduced-motion: reduce`에서는 등장 연출과 흐르는 줄, 스크롤 드로잉을 끄고 선을 처음부터 그린 상태로 둔다.
